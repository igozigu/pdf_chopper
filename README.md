# PDF Chopper (북마크 기반 PDF 자동 분할기)

PDF 파일을 업로드하면, 해당 PDF에 포함된 **북마크(목차) 항목 기준**으로 여러 개의 PDF 파일로 자동 분할해 주는 Windows용 데스크톱 프로그램입니다.

---

## 🌟 주요 기능 및 특징

1. **단일 실행 파일 (.exe)**:
   - 별도의 파이썬 설치나 환경 구성 없이 `PDF_Chopper.exe` 파일 하나만 더블클릭하여 바로 실행할 수 있습니다.
2. **드래그 앤 드롭 지원**:
   - PDF 파일을 창 안으로 마우스로 끌어다 놓거나, "파일 선택" 버튼을 통해 손쉽게 불러올 수 있습니다.
3. **분할 대상 미리보기**:
   - 업로드 즉시 감지된 북마크 목록, 분할될 순번, 페이지 범위(`p.1 ~ 15`), 총 페이지 수 등을 표로 확인할 수 있습니다.
4. **유연한 분할 레벨 설정**:
   - 기본값인 **최상위 목차 (1단계)**뿐만 아니라, **1~2단계 목차** 또는 **모든 세부 목차** 기준으로 분할 단위를 선택할 수 있습니다.
   - 첫 목차 이전 페이지(표지, 머리말 등)가 있는 경우 `00_시작부속.pdf`로 안전하게 보존 분할합니다.
5. **안전한 파일 및 폴더 생성**:
   - 원본 PDF가 위치한 폴더 안에 원본 파일명과 동일한 폴더를 생성하여 저장합니다.
   - 이미 같은 이름의 폴더가 있을 경우 덮어쓰지 않고 `파일명 (1)`, `파일명 (2)` 형태로 자동 분리 생성합니다.
   - 윈도우 파일명에 사용할 수 없는 특수문자(`\ / : * ? " < > |`)는 밑줄(`_`)로 자동 치환합니다.
6. **직관적인 결과 안내**:
   - 분할 진행률 표시바 및 작업 완료 시 팝업 안내창에서 **[결과 폴더 열기]** 버튼을 통해 저장된 폴더를 바로 열 수 있습니다.

## 🚀 빠른 실행 방법

### 방법 1: 단일 실행파일(.exe) 직접 실행
프로젝트 최상단 폴더에 있는 `PDF_Chopper.exe`를 더블클릭하여 실행합니다.

### 방법 2: Python 소스로 직접 실행
Python 3.10 이상이 설치된 환경에서 아래 명령어를 실행합니다:

```bash
# 1. 의존성 패키지 설치
pip install -r requirements.txt

# 2. 프로그램 실행
python main.py
```

---

## 🔨 .exe 파일 직접 빌드하기

프로그램을 수정한 후 다시 단일 실행 파일(.exe)로 패키징하려면 아래 방법 중 하나를 이용하세요:

### 1) 배치 파일 실행 (권장)
- `build.bat` 파일을 더블클릭합니다.

### 2) 파이썬 빌드 스크립트 실행
```bash
python build_exe.py
```

빌드가 완료되면 루트 디렉토리 및 `dist/` 폴더에 `PDF_Chopper.exe`가 생성됩니다.

## 📁 프로젝트 파일 구조

```
pdf_chopper/
├── PDF_Chopper.exe       # 배포용 단일 실행 파일
├── src/
│   ├── __init__.py
│   ├── pdf_splitter.py   # PDF 북마크 파싱 및 분할 핵심 로직
│   └── gui.py            # TkinterDnD2 기반 모던 GUI 애플리케이션
├── tests/
│   ├── __init__.py
│   └── test_splitter.py  # 단위 테스트 (pytest)
├── main.py               # 프로그램 엔트리포인트
├── build_exe.py          # PyInstaller 빌드 자동화 스크립트
├── build.bat             # 원클릭 빌드 배치 파일
├── requirements.txt      # 의존성 패키지 목록
├── README.md             # 프로젝트 설명서
└── walkthrough.md        # 기획 명세서
```

pytest tests/test_splitter.py -v

암호화 PDF 감지, 북마크 없는 PDF 처리, 특수문자 파일명 정제, 다단계 북마크 분할, 폴더 중복 처리 등 9개 항목의 단위 테스트가 수행됩니다.
